
# 坐标系定义与转换

为了符合机器人领域的通用标准并便于后续与 ROS 生态结合，本项目将弃用参考项目的坐标系，转而采用 **ROS 标准坐标系 (REP 103)** 进行动力学解算。

## 1. 动力学解算坐标系 (ROS Standard)

*   **世界坐标系 (World Frame)**: **ENU** (East-North-Up)
    *   **+X**: 东 (East)
    *   **+Y**: 北 (North)
    *   **+Z**: 天 (Up) - 重力方向为 -Z
*   **机体坐标系 (Body Frame)**: **FLU** (Forward-Left-Up)
    *   **+X**: 前 (Forward)
    *   **+Y**: 左 (Left)
    *   **+Z**: 上 (Up)

## 2. 渲染坐标系 (PyTorch3D)

PyTorch3D 使用的坐标系定义如下（用于后续渲染转换）：
*   **+X**: 向左 (Left)
*   **+Y**: 向上 (Up)
*   **+Z**: 向里 (In / Screen)

在将动力学状态传递给渲染器时，我们需要进行坐标系变换 (ROS -> PyTorch3D)。

## 3. 相机在那里？
*   **相机放在机体中心正前方10cm处，X=0.10，Y=0,Z=0**

## 4. 相机安装旋转约定 (`build_cam_mount_R`)

与参考项目 (DiffPhysDrone) 的 `R_cam` 矩阵完全一致。

默认 `cam_angle=10` → 相机向上仰视 10°，与参考项目行为一致。

*   **pitch** (默认 10°): 正值 → 相机向**上**倾斜（仰视），负值 → 向下（俯视）
*   **roll** (默认 0°): 正值 → 相机向**左**倾斜，负值 → 向右
*   **yaw** (默认 0°): 正值 → 相机向**左**偏转，负值 → 向右

内部构造: `R_mount = Rz(yaw) @ Rx(-roll) @ Ry(-pitch)`

## 5. 坐标系变换关系

| 变换 | 映射 | 说明 |
|------|------|------|
| ROS → PT3D | (x,y,z) → (-x, z, y) | `transform_pos_ros2pt3d` |
| OBJ → ROS | (x,y,z) → (-x, z, y) | `obj_to_ros` (自逆) |
| OBJ → PT3D | OBJ→ROS→PT3D = identity | **OBJ 坐标 = PT3D 坐标** |
| OBJ→Body | (x,y,z) → (x, -z, y) | `[:,[0,2,1]]*[1,-1,1]` 即 Rx(+90°) |
