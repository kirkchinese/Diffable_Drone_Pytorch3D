# E3D-5 MuJoCo 外部验证视频（非专家"眼见为实"件）

这些是把我们的步态策略部署到**外部仿真器 MuJoCo 全身 Go2**（一个我们没参与建模、
动力学比我们的孪生复杂得多的"真机替身"）上录的。你不需要懂数学，**看狗走得稳不稳、
直不直、快不快**即可核对结论。

| 视频 | 是什么 | 该看到什么 |
|---|---|---|
| `e3d5_openloop.mp4` | 纯预定步态，无策略修正 | 狗向前 trot，略慢于目标，不摔 → 我们的步态结构本身能迁到全身 Go2 |
| `e3d5_nominal.mp4` | **标称孪生**（无残差）训出的策略 | 走得最稳最直（身体倾斜 2–6°）、速度最接近目标 |
| `e3d5_corrected_struct.mp4` | **结构残差**修正的孪生训出的策略 | 与标称差不多，偶尔一个种子较差 |
| `e3d5_corrected_mlp.mp4` | **自由 MLP 残差**修正的孪生训出的策略 | **明显更晃、更蜷、更慢**（身体倾斜 9–11°）——反而最差 |

## 一句话结论（反直觉但重要）
把孪生"修正"得越像真机（按一步加速度衡量，MLP 修正到 97% 吻合），训出的策略迁到真机
**反而越差**（92 → 168 mm/s 速度误差）。原因：真机的差距（腿的惯量）在我们残差能表达的
范围之外，MLP 用虚假的足端力把数字凑对了，策略学会钻这个空子，到真机就露馅。
**结构残差因为只能调物理上真实的量，凑不出空子，所以退化得优雅（≈不修正）。**
