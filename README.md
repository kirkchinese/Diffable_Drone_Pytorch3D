# Diffable_Drone_Pytorch3D
一个基于Pytorch3D与Pytorch搭建的无人机可微分物理仿真平台。
# 更新日志 2026.1.12 
在训练时发现了莫名其妙的梯度爆炸Nan的问题，在AI的帮助下发现三个导致问题的错误点：
- 1. 旧版本的solve_attitude_from_thrust_and_goal_vec 中的 F.normalize 存在问题 - 当输入向量接近零时梯度会爆炸。
- 2. 就版本的acos处梯度爆炸 - 当 cos_theta 精确等于 ±1 时
- 3. PyTorch3D 透视投影的反向传播问题 - transform_points 中的除法在某些相机位置下产生 NaN 梯度，这是pytorch3D的问题，我们后面可以发一个issue给Pytorch3D的项目组。
最终的解决方案是：
- 1. drone_dynamics.py:117-120 - 使用安全归一化替代 F.normalize
- 2. drone_dynamics.py:147-172 - 使用安全归一化和软混合替代硬切换
- 3. drone_dynamics.py:383 - 将 acos 输入 clamp 到 [-1+1e-6, 1-1e-6]
- 4. train.py:231-243 - 使用 torch.no_grad() 包裹渲染调用
